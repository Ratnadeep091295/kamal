# Kamal Transport Website Handoff

This package contains the current approved desktop website preview for Kamal Transport.

Start here:
- `index.html` - Homepage
- `about.html` - About
- `services.html` - Services
- `fleet.html` - Equipment
- `careers.html` - Careers
- `contact.html` - Contact
- `quote.html` - Request a quote

Current approved constraints:
- Preserve the approved desktop layout, copy, typography, branding, navigation and button behavior.
- The homepage hero is locked and should remain untouched unless the client explicitly reopens it.
- The six service images are already placed according to the approved mapping.
- The About section uses the fleet drone photo in the body image position.
- Subsection headers use the road/sky/tree treatment with the truck removed and an even tint.
- Careers is currently the approved baseline version, not the experimental layout preview.
- Removed careers benefits should stay removed: full benefits, RRSP program, performance bonuses, recognition awards and paid holidays.

Careers approved benefit list:
- Year-round work
- Flexible scheduling
- Home every night
- Bi-weekly pay by direct deposit
- Dedicated truck
- On-site mechanics
- On-site driver trainer

Useful note:
The working project also contains experimental careers layout studies, but those were not approved as the live direction. This handoff package intentionally includes only the approved site files and shared assets needed to view the current version.

To preview locally, open `index.html` in a browser or serve this folder with a simple static server.
